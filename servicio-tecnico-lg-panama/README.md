# Servicio Técnico LG Panamá (SEO orgánico)

Sitio estático generado con `_fuente/generar.py` (ejecutar `python3 generar.py` dentro de `_fuente`).
- 295 páginas: inicio, 3 equipos (neveras, lavadoras, secadoras) con subpáginas, servicios por equipo, 46 zonas y zona × equipo, 34 fallas, 12 páginas de búsquedas clave y 20 guías.
- Antes de publicar: editar `_fuente/contenido.py` (DOMINIO, TEL/WA, GTM_ID, VERIFICACION) y volver a generar.
- Fotos de producto LG de lavadora, secadora y torre: pendientes (hoy se usan fotos de técnico). Nombres a reemplazar en `images/fotos/`: ver `_fuente/generar.py` (EQ_IMGS, HERO_CARDS).
